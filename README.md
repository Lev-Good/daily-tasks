# משימות יומיות (Daily Tasks)

תוכנת תזכורות יומיות לחלונות, בנויה על PowerShell + WPF.
התוכנה רצה במגש המערכת (system tray) ומזכירה לך משימות חוזרות או חד-פעמיות לפי לוח זמנים קבוע.

## תכונות

- הוספת משימות חד-פעמיות או חוזרות (יומי / שבועי לפי ימים), עם בחירת תאריך (היום, מחר או כל יום אחר)
- תזכורת עם חלון התראה + צליל, וצליל הצלחה בעת סימון ביצוע
- כפתור צליל בראש החלון לשליטה מהירה על השמעת צליל ההתראות
- אפשרות להנמנם (snooze) ולהגדיר תזכורת מוקדמת
- תצוגת משימות עם סינון: היום / מחר / השבוע / הכל
- גרירת משימות לסידור מחדש (המשימות שהושלמו יורדות לתחתית)
- התראה על משימות שהוחמצו בזמן שהתוכנה הייתה סגורה
- אפשרות להתחיל ממוזער למגש המערכת
- פעולה אוטומטית בכניסה ל-Windows (אופציונלי)
- אייקון אחיד בתוכנה, בשורת המשימות, במגש המערכת ובקיצורי הדרך
- לחיצה על הקיצור כשהתוכנה כבר פועלת - פותחת את החלון (לא יוצר עותק כפול)
- אין צורך בזכויות מנהל

## התקנה

### אפשרות א: קובץ התקנה (.exe)
הורידו את `DailyTasks-Setup.exe` מהמהדורות (Releases) והריצו אותו.
התוכנה תותקן אל `%LOCALAPPDATA%\DailyTasks`, ייווצרו קיצורי דרך בשולחן העבודה ובתפריט התחל, והתוכנה תיפתח מיד עם סיום ההתקנה.

### אפשרות ב: ידנית
1. הורידו את קוד המקור (Code > Download ZIP).
2. חלצו את הארכיון.
3. לחצו פעמיים על `DailyTasks.cmd` (או על `install.cmd` להתקנה מלאה עם קיצורי דרך).

> הערה: ייתכן ש-Windows יציג אזהרת SmartScreen עבור קובץ ה-.exe — הקובץ אינו חתום בתעודה. לחצו "מידע נוסף" > "הרץ בכל זאת".

## שימוש

- פתחו את התוכנה מהקיצור או מהמגש.
- אם התוכנה כבר רצה (במגש), לחיצה על הקיצור תפתח את החלון.
- לחצו על כפתור "+" כדי ליצור משימה חדשה עם אפשרויות מלאות.
- סמנו משימות שבוצעו — יושמע צליל הצלחה, והכותרת תהיה מחוקת בקו.
- בטל-את-הסימון של משימה יחזיר אותה למצב ממתין.
- גררו משימות למעלה ולמטה כדי לקבוע את הסדר שלהן.
- מקשי קיצור: Ctrl+F לחיפוש, Esc לסגירת החיפוש.
- הסרת התקנה: הרצת `uninstall.cmd` מתוך החבילה.

## מבנה הקבצים

| קובץ | תיאור |
| --- | --- |
| `DailyTasks.ps1` | התוכנה הראשית (PowerShell + WPF) |
| `DailyTasks.cmd` | קובץ הפעלה פשוט |
| `DailyTasks.exe` | עטיפת הפעלה (C#) עם אייקון משלו |
| `DailyTasks.ico` | אייקון התוכנה |
| `setup.ps1` / `install.cmd` | מתקין לקיצורי דרך והתקנה |
| `uninstall.ps1` / `uninstall.cmd` | הסרת התקנה (קיצורי דרך וקבצים) |
| `sound.wav` / `success.wav` | צלילי התראות |
| `tasks.json` | שמירת המשימות (נוצר אוטומטית, לא נכלל במאגר) |

## הוצאת גרסה חדשה

1. עדכנו את `$script:AppVersion` ב-`DailyTasks.ps1` (למשל `'1.5.0'`) ואת `CHANGELOG.md`.
2. דחפו את השינויים ל-`main`.
3. צרו תג גרסה ודחפו אותו — ה-workflow ב-`.github/workflows/release.yml` בונה את `DailyTasks-Setup.exe` ואת החבילה הניידת ומפרסם אותם אוטומטית:

```bash
git tag v1.5.0 && git push origin v1.5.0
```

התוכנה בודקת עדכונים מול `releases/latest` בכל פתיחה (ובתפריט המגש), מורידה את `DailyTasks-Setup.exe` ומתקינה אותו — הנתונים נשמרים.
