משימות יומיות - חבילת התקנה
=============================

מה כוללת החבילה:
- DailyTasks.ps1 - קובץ התוכנה הראשי
- DailyTasks.cmd - קובץ הפעלה פשוט
- sound.wav, success.wav - צלילי התראות
- tasks.json - המשימות הקיימות שלך (אם יש)
- install.cmd + setup.ps1 - המתקין

איך מתקינים:
1. חלצו את התיקייה מהארכיון ZIP.
2. לחצו פעמיים על install.cmd.
3. המתקין יעתיק את התוכנה לתיקייה:
   %LOCALAPPDATA%\DailyTasks
4. ייווצרו קיצורי דרך בשולחן העבודה ובתפריט התחל
   ("משימות יומיות").

איך מפעילים:
- לחיצה כפולה על הקיצור "משימות יומיות" (שולחן העבודה או תפריט התחל).
- התוכנה מופעלת מהמגש (צד ימין למטה בשורת המשימות).

כדי שהתוכנה תופעל אוטומטית בכניסה ל-Windows:
- פתחו את התוכנה, סמנו את התיבה "הפעלה אוטומטית" בחלון הראשי.

הערות:
- ההתקנה אינה דורשת זכויות מנהל - התוכנה מותקנת לחשבון המשתמש.
- כל קבצי התוכנה והנתונים נשמרים יחד בתיקיית ההתקנה.
- גיבוי המשימות: שמרו עותק של קובץ tasks.json מתיקיית ההתקנה.
